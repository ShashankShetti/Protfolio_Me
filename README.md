# Hi there! 👋 Welcome to My Portfolio

This is the source code for my personal portfolio website, where I showcase my projects, skills, and background.

🌐 **Check out the live site:** [shashank-shet.vercel.app](https://shashank-shet.vercel.app/)

## 💻 What's Inside?

* **About Me:** A little bit about who I am and what I do.
* **Projects:** Highlights of the coding projects I've built.
* **Skills:** The technologies and tools I work with.
* **Contact:** Easy ways to get in touch with me.

## 🛠️ Technologies Used

* HTML5 / CSS3 / JavaScript
* Hosted on Vercel

## 🚀 How to Run It Locally

Want to test or look at the code on your computer? Just follow these steps:

1. **Download the code:**
   ```bash
   git clone https://github.com/ShashankShetti/Protfolio_Me.git
   ```

2. **Open the folder:**
   ```bash
   cd Protfolio_Me
   ```

3. **View the site:**
   Double-click on `index.html` to open it right in your web browser!
